# DOC-VOICE-008 语音点餐开发任务与实施计划

| 项目 | 内容 |
|---|---|
| 文档编号 | DOC-VOICE-008 |
| 版本 | v1.0 |
| 状态 | 开发基线 |
| 更新时间 | 2026-08-18 |

## 1. 阶段一：领域与接口

- 将现有语音 schema 扩展为 `rawText`、`normalizedText`、候选和结构化 modifiers。
- 为 `OrderItem.modifiers` 增加类型和 Zod 校验。
- 新增 VoiceSession 内存仓储，定义过期时间和状态机。
- 改造 `/api/orders/voice-preview`，保证无副作用。
- 增加幂等键和服务端菜单、桌号、价格校验。

## 2. 阶段二：浏览器语音能力

- 实现 `SpeechRecognitionAdapter`。
- 实现权限、超时、空文本、浏览器不支持和错误码处理。
- 实现 `SpeechSynthesisAdapter`，支持中文优先和英文降级。
- 实现 VoiceButton 状态机及大屏/平板/手机响应式样式。

## 3. 阶段三：解析与纠错

- 建立菜品别名、方言词、同音词和数量词配置。
- 完成多菜品、多数量、多修饰词解析。
- 完成候选展示、用户修正和低置信度策略。
- 连续两次失败后创建工作人员会话。

## 4. 阶段四：订单与实时同步

- 将确认后的语音预览映射到订单草稿。
- 同步订单明细结构化口味到后厨和传送带视图。
- 增加语音会话 WebSocket 事件。
- 增加临时音频可选上传和定时清理；默认关闭长期保存。

## 5. 阶段五：测试与演示

- 完成 DOC-VOICE-007 中的单元、集成和端到端测试。
- 使用真实设备验证麦克风权限、噪声、老人慢速表达和方言候选。
- 记录浏览器兼容性和已知问题。
- 现场演示前预置手动点餐兜底和工作人员接管账号。

## 6. 后续连续对话

连续对话应在单轮版本稳定后开发：复用 `VoiceSession`、槽位模型、解析器和确认机制，新增 `turns`、上下文超时、打断和逐槽位追问；不得绕过现有订单确认和安全校验。
