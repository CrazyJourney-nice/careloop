## 1. 异常处理矩阵

| 异常 | 用户反馈 | 系统动作 |
|---|---|---|
| 浏览器不支持 | 请使用手动点餐 | 禁用语音按钮 |
| 无麦克风权限 | 请允许麦克风或手动点餐 | 不重试权限弹窗 |
| 环境太吵 | 没听清，请靠近一点再说 | 保留本轮文本，允许重试 |
| 方言/吐字不清 | 展示最多 3 个候选 | 用户选择或转工作人员 |
| 菜品下架 | 该菜暂时不可点 | 不加入购物篮，提示替代菜 |
| 口味不支持 | 当前菜品不能设置该要求 | 允许删除该要求或请求工作人员 |
| 会话过期 | 请重新开始 | 删除临时数据 |
| 网络断开 | 当前无法提交 | 本地保留未提交草稿，禁止重复提交 |

## 2. 安全要求

- 语音接口和音频上传仅允许 HTTPS。
- 服务端不能信任前端置信度、菜品价格、桌号和口味字段，必须重新校验。
- 订单创建使用幂等键，避免用户重复点击造成重复订单。
- 会话 ID 使用不可预测随机值，不在 URL 中暴露手机号等个人信息。
- 工作人员查看语音会话应记录 `claimedBy`、修改前后值和时间。
- 原始转写可能包含手机号、姓名等个人信息，日志中必须脱敏。
- 录音上传大小、时长、MIME 类型必须限制；拒绝可执行文件和异常扩展名。
- 所有音频、转写、候选数据都必须有过期清理策略。

## 3. 无障碍要求

- 支持键盘和触摸操作，不能只依赖语音。
- 按钮提供可读的 `aria-label`。
- 识别状态使用文字、颜色和图标共同表达。
- 不使用快速闪烁动画，不以声音作为唯一错误提示。
