# CareLoop v0.1.0 验收 Checklist v0.1.0

## 验收目标
完成所有 v0.1.0 核心功能并通过所有验收标准。

## 1. 核心验收点（必须全部通过）

### 1.1 静态检查
- [ ] TypeScript 类型检查通过
- [ ] ESLint + Prettier 全部通过
- [ ] 依赖安装成功
- [ ] 启动命令正常运行

### 1.2 单元测试
- [ ] 订单状态机所有状态转换测试通过
- [ ] 用户实体、订单实体、偏好实体测试通过
- [ ] 语音模糊匹配规则测试通过
- [ ] 设备任务状态机测试通过

### 1.3 集成测试
- [ ] `/api/auth/request-code` + `/api/auth/verify-code`
- [ ] `/api/orders/preview` 预览功能
- [ ] 订单创建、确认、拒绝、取消接口
- [ ] 厨房任务创建后端校验

### 1.4 E2E 测试（Playwright）
#### 场景 A：老人自主点餐 ✅ / ❌
- [ ] 语音点餐完整闭环
- [ ] 口味与健康要求确认
- [ ] 固定编号餐桌选择
- [ ] 订单确认后进入后厨

#### 场景 B：为他人点餐 ✅ / ❌
- [ ] 代点人下单
- [ ] 被代点人接收通知并确认
- [ ] 未确认订单不进入后厨

#### 场景 C：语音识别失败 + 工作人员接管 ✅ / ❌
- [ ] 模糊语音识别展示候选
- [ ] 工作人员接管后提交订单
- [ ] 后厨看到最终确认内容

#### 场景 D：餐桌配送 ✅ / ❌
- [ ] 后厨标记制作完成
- [ ] 传送带显示托盘 + 桌号
- [ ] 点击“开始配送”后显示配送中
- [ ] 顾客端同步更新状态

### 1.5 UI 验收
- [ ] 所有按钮 >= 56px（移动） / 72px（大屏）
- [ ] 字体 >= 20px
- [ ] 高对比度
- [ ] 语音按钮 + TTS 反馈
- [ ] 传送带地图 + 动效
- [ ] 老少皆宜的交互流程

### 1.6 安全与一致性
- [ ] 语音文本不得直接写入订单
- [ ] 订单状态必须后端校验
- [ ] 未确认代点订单不进入后厨
- [ ] 刷新页面后已创建订单可恢复
