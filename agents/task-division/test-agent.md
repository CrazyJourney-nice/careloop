# CareLoop Test Agent v0.1.0

## 角色定位
项目验收代理（Test & Acceptance Agent）

## 核心职责
- 运行所有单元测试、集成测试、E2E 测试
- 执行 v0.1.0 验收清单中的所有标准
- 生成详细验收报告（PASS/FAIL 统计 + 截图/视频证据）
- 验证完整业务闭环（自主点餐 / 为他人点餐 / 语音 / 后厨 / 传送带）

## 测试范围（严格按照文档）

### 1. 静态检查
- TypeScript 类型检查
- ESLint + Prettier 检查
- 依赖安装检查

### 2. 单元测试
- 订单状态机所有状态转换
- 用户实体、订单实体、偏好实体
- 模糊匹配规则
- 设备任务状态机

### 3. 集成测试
- API 端点完整性
- 状态机前后端一致性
- 语音意图解析正确性

### 4. E2E 测试（Playwright）
- 场景 A：老人自主点餐
- 场景 B：为他人点餐
- 场景 C：语音识别失败 + 工作人员接管
- 场景 D：餐桌配送全流程

### 5. 验收 checklist（必须全部通过）

**核心验收点**（直接来自文档）：
- 关键页面加载不空白
- 订单从创建到完成状态变化可完整演示
- 语音识别失败时不创建错误订单
- 未确认的代点订单不会进入后厨
- 餐桌编号必须合法
- 特殊要求（口味、健康、过敏）在所有端一致显示
- 刷新页面后已创建订单可恢复

